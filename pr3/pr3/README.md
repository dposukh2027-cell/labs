# PR3 — інтеграція LLM через API

Цей проєкт реалізує веб-застосунок служби підтримки інтернет-магазину на FastAPI.

## Структура

- `app/` — основний код застосунку
- `static/` — статичні файли фронтенду
- `templates/` — HTML шаблони
- `context.md` — правила магазину, які використовуються як джерело правди
- `scripts/` — сценарії порівняння конфігурацій моделі
- `.env.example` — шаблон змінних середовища

## Швидкий старт

1. Створіть віртуальне середовище:
   `python -m venv .venv`
2. Активуйте середовище:
   ` .\.venv\Scripts\Activate.ps1 `
3. Встановіть залежності:
   `pip install -r requirements.txt`
4. Скопіюйте конфіг:
   `Copy-Item .env.example .env`
5. Вкажіть реальний ключ Google Gemini в `.env`.
6. Запустіть сервер:
   `uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`

## Підключення до Gemini

Проєкт використовує OpenAI-сумісний інтерфейс для Google Gemini:

- `LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/`
- `LLM_MODEL_NAME=gemini-2.0-flash`

## API

- `GET /` — веб-інтерфейс
- `POST /api/answer` — відправка звернення клієнта
- `GET /api/health` — перевірка стану сервісу
- `POST /api/compare` — порівняння двох конфігурацій генерації
