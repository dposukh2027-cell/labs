# RAG помічник для магазину "Сузір'я"

Застосунок шукає релевантні фрагменти в документах Markdown у `docs/` і передає запит разом із знайденим контекстом до OpenAI-сумісної моделі (зокрема Gemini API). Модель має відповідати лише за цими фрагментами; якщо потрібної інформації немає, помічник повідомляє про це.

## Структура

- `app/` — код програми
- `docs/` — база знань
- `eval/` — перевірка на питаннях з відомими відповідями
- `scripts/` — перевірка середовища

## Запуск

У PowerShell з папки проєкту:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

У `.env` вкажіть ключ і модель Gemini:

```env
OPENAI_API_KEY=ваш_ключ_із_Google_AI_Studio
OPENAI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
MODEL_NAME=gemini-3.8-flash
```

Не додавайте `.env` до системи контролю версій і не надсилайте ключ у чат. Під час відповіді запит і знайдені фрагменти документів надсилаються до вибраного API провайдера.

Запуск сервера:

```powershell
python -m uvicorn app.api.main:app --reload --host 127.0.0.1 --port 8000
```

Відкрийте <http://127.0.0.1:8000>. Щоб зупинити сервер, натисніть `Ctrl+C`.

## Індекс документів і приватність

Під час запуску застосунок перебудовує `docs/index.json` із Markdown-файлів у `docs/`. До індексу потрапляють лише документи з метаданими `audience: клієнти` і `status: чинний`. Внутрішні, архівні, неописані метаданими файли та `docs/README.md` пропускаються. Після редагування або додавання документів перезапустіть сервер, щоб перебудувати індекс. Файл індексу є кешем — не редагуйте його вручну.

## Перевірка

Перевірка синтаксису:

```powershell
python -m compileall app
```

Оцінювання запускає запити до налаштованої LLM:

```powershell
python -m eval.run_eval
```
