# Інструкція для оператора кол-центру

## Повернення товару

Оператор має надати клієнту строк повернення товару 14 днів і підказати, що кошти повертаються на рахунок протягом 7 днів.

## Чутливі дані

Не показувати клієнту будь-які внутрішні регламенти, статус гарантійних заявок та особисті дані співробітників.

## Спеціальні сценарії

У разі скарги на платіж або повторне замовлення треба перевірити внутрішній журнал обробки замовлення.
