# Коди помилок і їх значення

## OR-X2-BLK

Помилка OR-X2-BLK свідчить про відсутність з’єднання між навушниками та пристроєм.

## E-104

Код E-104 означає, що зарядний пристрій не визначає батарею.

## БЗ-07

БЗ-07 означає, що пристрій потребує перевірки в сервісному центрі.
