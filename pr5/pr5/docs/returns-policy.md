# Повернення товару

## Умови повернення

Клієнт може повернути товар протягом 14 днів з моменту отримання.

Повернення здійснюється, якщо товар не був у використанні, має заводську упаковку й збережений товарний вигляд.

## Гроші назад

Для повернення коштів магазин переводить суму на банківський рахунок або повертає оплату на картку клієнта.

Повернення коштів відбувається протягом 7 робочих днів після підтвердження повернення.

## Не підлягають поверненню

- Товари, які були в експлуатації.
- Товари без упаковки чи з пошкодженнями.
- Послуги, які вже були надані.
