# База знань магазину «Сузірʼя»

Цей документ описує, як працює база знань і які документи в ній є.

## Основні правила

- Усі питання клієнтів мають відповідати правилам повернення, доставки й гарантії.
- Фрагменти індексуються окремо, щоб пошук повертав точні відповіді.
- Підказки для персоналу не показуються клієнтам.

## Принципи пошуку

Семантичний пошук використовує ембедінги для порівняння змісту, а ключові слова — для буквальних збігів.
