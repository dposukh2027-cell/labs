# Поширені питання

## Чи є підтримка 24/7?

Так, служба підтримки працює цілодобово для клієнтів, які мають активну гарантію.

## Чи можна повернути пристрій після 14 днів?

Тільки якщо це гарантійний випадок або якщо в договорі передбачені винятки.
